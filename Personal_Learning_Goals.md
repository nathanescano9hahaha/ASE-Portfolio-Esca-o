1. **Explain ASE clearly.** Be able to describe Agentic Software Engineering and how agents differ from traditional applications by the end of Week 4.
2. **Use Git confidently.** Commit regularly with clear messages, use branches, and keep this portfolio updated every week.
3. **Apply Agile/Scrum.** Plan my work in short sprints and reflect on what to improve after each one.

5. **Build a small agent.** Create a simple, human-supervised AI agent with documented limits and permissions before the end of the term.

- Weekly commits to this repository
- Completed activities submitted on time
- A short self-review at the end of each sprint
